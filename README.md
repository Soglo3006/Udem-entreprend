# Site Web de UdeM Entreprend 

Le site web de UdeM Entreprend est une plateforme web développée pour présenter le club d'entrepreneuriat de l'Université de Montréal, ses événements, ses programmes et ses partenaires. Elle permet également aux étudiants de s'impliquer en tant que bénévoles ou contributeurs, offrant ainsi une expérience interactive et complète.

Le projet illustre un full-stack : développement frontend moderne, backend performant et gestion de données structurée pour suivre les interactions des utilisateurs.

## Technologies

### Frontend
* React.js pour la structure et la navigation
* Tailwind CSS pour un design moderne et responsive
* Joy UI et Lucide React pour les composants et les icônes
* HTML pour la base des pages

### Backend
* FastAPI pour gérer les actions du frontend et l'ensemble des interactions
* PostgreSQL pour stocker les formulaires de bénévoles, les feedbacks et les inscriptions aux événements
* Déploiement backend sur Render
* Déploiement frontend sur Netlify

## Fonctionnalités principales
* Présentation du club : mission, valeurs, équipe actuelle et passée
* Affichage des événements : futurs, en cours et passés
* Gestion des programmes : mentorat, ateliers, formations
* Section partenaires et ressources pour les étudiants entrepreneurs
* Formulaire pour devenir bénévole ou contributeur
* Suivi des inscriptions aux événements et collecte de feedbacks
* Galerie photo et organisation des fichiers séparés pour un site structuré et maintenable
